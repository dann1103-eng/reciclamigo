# Reciclamigo — Fase 0: Base — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar lista la base compartida (proyecto Next.js, identidad visual, esquema Supabase con RLS/RPC, seeds, login demo con selector de rol, deploy) sobre la que el Track A y el Track B construyen en paralelo.

**Architecture:** Next.js 16 App Router + TypeScript en `src/`. Supabase (Postgres + PostGIS + Auth + Storage) con migraciones versionadas en `supabase/migrations/`. Toda transición de estado del mercado pasa por funciones RPC `security definer`; la UI lee tablas con RLS y vistas agregadas. Lógica de dominio pura en `src/lib/domain/` con tests Vitest. Cada track trabaja en su carpeta `src/features/<área>/`.

**Tech Stack:** Next.js 16.4, React 19, TypeScript, Tailwind CSS 4, shadcn/ui, @supabase/ssr 0.12 + @supabase/supabase-js 2, Supabase CLI 2, Leaflet 1.9 + react-leaflet 5, Recharts 3, qrcode, lucide-react, zod 4, Vitest 5, Playwright 1.64, tsx.

**Spec:** `docs/superpowers/specs/2026-10-17-reciclamigo-mvp-design.md`

## Global Constraints

- UI en español (es-SV), montos en USD. Identificadores de código en inglés; valores de enums de BD en español (`generador`, `publicado`, …) tal como en el spec.
- Next.js 16: el archivo de sesión es `src/proxy.ts` (no `middleware.ts`).
- Variables de entorno: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SECRET_KEY` (solo servidor), `DEMO_PASSWORD`, `DEMO_RESET_TOKEN`, `NEXT_PUBLIC_DEMO_MODE`, `NEXT_PUBLIC_SITE_URL`.
- Un solo proyecto Supabase (decisión del usuario) para local, Preview y Production.
- CO₂e evitado = kg × 2.0. m³ de vertedero liberados = toneladas × 3.
- Precios por kg: PET 0.20, HDPE 0.18 (propuesta); LDPE 0.10, PP 0.15, PS 0.05 (provisionales).
- Polímeros y número de resina: PET 1, HDPE 2, LDPE 4, PP 5, PS 6.
- Nombres de negocios y personas en seeds: siempre ficticios.
- La alcaldía (`municipalidad`) es solo lectura: no lee `lots`, `pickups` ni datos de contacto; toda RPC operativa la rechaza.
- `main` siempre desplegable; migración nueva por cambio, nunca editar una ya fusionada.

## Review Focus

- Polímero/kg inválidos en `publish_lot` (kg ≤ 0, kg > 10000, ventana de retiro invertida) → error claro, sin lote creado. Test en Task 4.
- Dos reservas del mismo lote (doble clic o dos recicladores) → la segunda falla con "El lote ya no está disponible". Test en Task 4.
- Cuenta de alcaldía intentando cualquier operación o leyendo `lots`/`profile_private` → error o lista vacía. Test en Task 4.
- "Reiniciar demo" sin token o con token incorrecto → 401 y datos intactos. Test en Task 4.
- Sesión inexistente entrando a `/comercio`, `/reciclador`, `/alcaldia` → redirige a `/entrar`; rol equivocado → redirige al home de su rol. Verificación en Task 5.

## Decisiones del builder (desviaciones menores del spec, mismo efecto)

- **Contacto separado:** `whatsapp`, `address` y `location` del perfil van en `profile_private`, legible solo por `generador`/`valorizador`. Así la alcaldía no ve contacto ni ubicación exacta.
- **Color del polímero** vive solo en TypeScript (`src/lib/domain/polymers.ts`); la BD guarda código, número de resina, nombre y precio.
- **Publicar** también es RPC (`publish_lot`), no insert directo: fija ubicación y precio desde el servidor.
- **`reset_demo`** se implementa en TypeScript (`src/lib/demo/seed.ts`) con la secret key; lo usan el script `npm run seed` y la ruta `/demo/reset`. Mismo contenido para ambos.
- **Certificado público** se lee con la RPC `get_certificate(code)` (concedida a `anon`), sin abrir tablas a usuarios anónimos.
- **Vistas agregadas** (`profile_impact`, `impact_monthly`, `impact_heat`) corren con privilegios del dueño a propósito: exponen solo totales, nunca contacto.

### Task 3: Esquema Supabase (migraciones, RLS, RPC, storage)

**Prerrequisito del usuario:** proyecto Supabase creado (hecho); `.env.local` con sus llaves; en su terminal: `npx supabase login` y `npx supabase link --project-ref <ref>`.

**Files:**
- Create: `supabase/config.toml` (`npx supabase init`), `supabase/migrations/20261017000100_schema.sql`, `…000200_rls.sql`, `…000300_views.sql`, `…000400_rpc.sql`, `…000500_storage.sql`, `src/types/database.ts` (generado)

**Interfaces:**
- Produces (SQL, todo en `public`):

```sql
create extension if not exists postgis with schema extensions;
create type user_role as enum ('generador','valorizador','municipalidad');
create type lot_modality as enum ('venta','trueque','donacion');
create type lot_status as enum ('publicado','reservado','entregado','completado','cancelado');
create type payment_method as enum ('efectivo','transferencia','chivo_wallet');

polymers(code text pk, resin_number smallint unique not null, name text not null,
         price_per_kg numeric(6,2) not null check (price_per_kg >= 0))   -- + insert de los 5 polímeros
profiles(id uuid pk references auth.users on delete cascade, role user_role not null,
         display_name text not null, org_type text not null, municipality text not null,
         zone text not null, verified boolean not null default false, created_at timestamptz default now())
profile_private(id uuid pk references profiles on delete cascade, whatsapp text,  -- formato 503XXXXXXXX
         address text, location extensions.geography(Point,4326) not null)
lots(id uuid pk default gen_random_uuid(), generator_id uuid not null references profiles on delete cascade,
     polymer_code text not null references polymers, estimated_kg numeric(8,2) not null check (estimated_kg > 0 and estimated_kg <= 10000),
     photo_urls text[] not null default '{}' check (cardinality(photo_urls) <= 3),
     pickup_from timestamptz not null, pickup_to timestamptz not null, check (pickup_to > pickup_from),
     modality lot_modality not null, price_per_kg numeric(6,2) not null default 0, notes text,
     status lot_status not null default 'publicado', location extensions.geography(Point,4326) not null,
     created_at timestamptz not null default now())          -- índice GIST en location, btree en status
pickups(id uuid pk default gen_random_uuid(), lot_id uuid unique not null references lots on delete cascade,
        collector_id uuid not null references profiles on delete cascade, reserved_at timestamptz not null default now(),
        delivered_at timestamptz, completed_at timestamptz, confirmed_kg numeric(8,2) check (confirmed_kg > 0),
        total_amount numeric(10,2), payment_method payment_method, certificate_code text unique)
ratings(id uuid pk default gen_random_uuid(), pickup_id uuid not null references pickups on delete cascade,
        rater_id uuid not null references profiles, ratee_id uuid not null references profiles,
        stars smallint not null check (stars between 1 and 5), comment text,
        created_at timestamptz not null default now(), unique (pickup_id, rater_id))
```

  - `my_role() returns user_role` — `stable security definer`, rol de `auth.uid()`.
  - RLS (activar en todas): `polymers` select a `anon, authenticated`; `profiles` select a `authenticated`; `profile_private` select si `my_role() in ('generador','valorizador')`; `lots` select si `my_role() in ('generador','valorizador')`; `pickups` select si `collector_id = auth.uid()` o el lote es del usuario; `ratings` select a `authenticated`. **Ninguna** policy de insert/update/delete: las escrituras van por RPC.
  - Vistas (grant select a `authenticated`):
    - `profile_impact(profile_id, role, display_name, org_type, municipality, verified, lots_published, completed_count, completed_kg, total_amount, rating_avg, rating_count)` — `completed_*` y `total_amount` cuentan retiros `completado` donde el perfil es generador o reciclador.
    - `impact_monthly(month date, generator_id, municipality, polymer_code, completed_kg, total_amount, pickups_count)` — `month = date_trunc('month', completed_at)`.
    - `impact_heat(municipality, lat, lng, completed_kg)` — ubicación del lote redondeada a 3 decimales, agrupada por municipio del comercio.
  - RPC (`security definer`, `set search_path = ''`, `grant execute … to authenticated`; errores en español con `raise exception`):
    - `publish_lot(p_polymer_code text, p_estimated_kg numeric, p_pickup_from timestamptz, p_pickup_to timestamptz, p_modality lot_modality, p_photo_urls text[] default '{}', p_notes text default null) returns uuid` — solo `generador`; ubicación desde `profile_private`; `price_per_kg` = precio del polímero si `venta`, si no 0.
    - `nearby_lots(p_lat double precision, p_lng double precision, p_radius_m integer, p_polymers text[] default null) returns table(id uuid, generator_id uuid, generator_name text, polymer_code text, estimated_kg numeric, price_per_kg numeric, modality lot_modality, pickup_from timestamptz, pickup_to timestamptz, photo_urls text[], notes text, lat double precision, lng double precision, distance_m double precision)` — `security invoker`, solo `publicado`, `ST_DWithin`, orden por distancia.
    - `reserve_lot(p_lot_id uuid) returns uuid` — solo `valorizador`; `update … where status = 'publicado'`; si 0 filas → `'El lote ya no está disponible'`; crea `pickups`, devuelve su id.
    - `mark_delivered(p_pickup_id uuid) returns void` — solo el generador dueño; lote `reservado` → `entregado`, fija `delivered_at`.
    - `complete_pickup(p_pickup_id uuid, p_confirmed_kg numeric, p_payment_method payment_method) returns text` — solo el reciclador del retiro; lote `entregado` → `completado`; `total_amount = confirmed_kg × lots.price_per_kg`; `certificate_code = 'RCA-' || año || '-' || 6 caracteres hex en mayúscula`; devuelve el código.
    - `rate_pickup(p_pickup_id uuid, p_stars smallint, p_comment text default null) returns void` — solo partes del retiro, retiro `completado`; `ratee` = la otra parte.
    - `get_certificate(p_code text) returns table(code text, completed_at timestamptz, generator_name text, generator_org_type text, municipality text, collector_name text, collector_org_type text, polymer_code text, polymer_name text, resin_number smallint, confirmed_kg numeric)` — `grant execute` también a `anon`.
  - Storage: bucket público `lot-photos` (5 MB, `image/jpeg|png|webp`); policy de insert en `storage.objects` para `authenticated` con `bucket_id = 'lot-photos' and (storage.foldername(name))[1] = auth.uid()::text and public.my_role() = 'generador'`.
